# NEXO
NexoCTI es una plataforma con IA que cosecha y publica convocatorias en CTI, I+D+I y Educación Superior. Gestiona plazos de aval interno y cierre oficial, genera guías con tips para postular y articula consorcios entre investigadores e instituciones, elevando la tasa de éxito en fondos nacionales e internacionales.
